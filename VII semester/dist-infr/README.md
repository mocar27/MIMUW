# ***Engineering distributed infrastructure***

Engineering distributed infrastructure course included working on a project in a team of 4, alongside Google's tutor.

Our team was responsible for working on [MapReduce](https://en.wikipedia.org/wiki/MapReduce) project, it's implementation and later deployment on GKE. 

Project was made in collaboration with [@maclick](https://github.com/maclick), [@zortenburger](https://github.com/zortenburger) and [@JacquesWhite](https://github.com/JacquesWhite).

Project is public on GitHub and can be found [here](https://github.com/JacquesWhite/MapReduce).
