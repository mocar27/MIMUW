# Basics of Game Development

Basics of Game Development course included one assignment, that students were intended to work on during the whole semester.

As a team of two, we've developed our variation of Subway Surfers game in Unreal Engine 5/C++. The game includes a simple character controller, that allows to move the character left and right, jump and slide. The character is running on a track, that is generated on the go. The track is divided into three lanes, and the character can switch between them. The game also includes a simple scoring system, that rewards the player for collecting coins and avoiding obstacles.

The project was implemented in Unreal Engine 5/C++ additionally using blueprints and textures from Unreal Fab.

More detailed description, as well as, the source code of the project can be found [here](https://github.com/WingedFoxx/mimuw-surfers).
