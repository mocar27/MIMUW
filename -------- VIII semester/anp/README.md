# Advanced network programming 

Advanced network programming course included one enormous assignment throught the whole classes.

Students were delegated with implementing type of Torrent-service (distributed P2P) with enabling of sharing files
with each other connected peer. Additionally to P2P communication, there was central server communication
for verification, handshake and introduction to the service purposes. 

More detailed description can be found in [`project/project-description.pdf`](https://github.com/mocar27/MIMUW/blob/main/VIII%20semester/anp/project/project-description.pdf) file [here](https://github.com/mocar27/MIMUW/blob/main/VIII%20semester/anp/project/project-description.pdf).

Whole project was made in collaboration with [@Toomimi](https://github.com/Toomimi) and can be found [here](https://github.com/Toomimi/advanced-network-programming-project),
but in case it's not available or the repository is private, I've included the project in the `project/` directory as well.

In addition to the main project, there were every week classes with in-lab tasks to do.
Almost all of the small lab tasks can be found [here](https://github.com/mocar27/advanced-networks).
