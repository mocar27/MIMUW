# Computer Graphics

Computer graphics course included one assignment, that students were intended to work on during the whole semester.

The idea of the project was entirely up to students. My project was a simple, nicely represented **Solar System**.
It was recognized by the tutors for later grade increment at the end of the semester.

The project was implemented in C++ using OpenGL, GLSL and ImGui. It includes a simple camera system, that allows to move around the scene and look at it from different angles. The planets are represented as spheres with textures, and they orbit around the sun. The sun is represented as a bright sphere with a texture that simulates the solar surface.

More detailed description, as well as, the source code of the project can be found [here](https://github.com/mocar27/graphics-project).
