# ***Compiler construction***

Compiler construction course included implementation of two compilers for custom-made languages, one smaller than the other one.
The Instant compiler being the introduction into compiler construction, while the Latte compiler,
it's design, implementaion and optimization being the main objective of the course.

The projects, their description and implementation are public on my GitHub profile and can be found using the links below.

First project - [Instant compiler](https://github.com/mocar27/instant-compiler) can be found [here](https://github.com/mocar27/instant-compiler).

Second project - [Latte compiler](https://github.com/mocar27/latte-compiler) can be found [here](https://github.com/mocar27/latte-compiler).
